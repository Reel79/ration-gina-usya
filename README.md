# Рацион Джины и Уси

Калькулятор общей смеси, порций и покупок. Вкладка «Покупки» сразу показывает поле количества дней и нужные продукты. Установленная веб-версия работает без аккаунта. Данные хранятся на устройстве, без сервера и синхронизации.

## Локальный запуск

Из папки приложения:

```powershell
python tools/build.py
python -m http.server 8765 --bind 127.0.0.1
```

Откройте http://localhost:8765/. Для проверки подпапки:

```powershell
python tools/prepare_pages.py
python -m http.server 8766 --bind 127.0.0.1 --directory .deployment/pages
```

Откройте http://localhost:8766/ration-gina-usya/.

## Проверки и сборка

Установите Node.js LTS с https://nodejs.org/en/download, затем:

```powershell
node tests/core.test.js
node tests/sw.test.js
python tools/build.py --check
```

После изменения любого файла приложения выполните `python tools/build.py`. Версия содержит UTC-время и хеш содержимого; повторная сборка без изменений сохраняет версию. APP_VERSION определяется только в генерируемом version.js, который используют приложение и sw.js. Номер виден внизу настроек. Новая версия устанавливается по кнопке «Обновить», данные сохраняются.

## Расчёты

Оригинал защищён: изменения создают копию. Сухой вес крупы рассчитывается через коэффициент разварки; калории сухой крупы делятся на этот коэффициент. Измеренный выход действует до изменения состава.

У масла хранятся ккал/100 г и граммы в ложке. Калории ложки всегда вычисляются как граммы × ккал/100 г / 100. Оливковое: 899 и 13,5; кокосовое: 892 и 13; льняное: 884 и 13,5. Данные сохраняют полную точность, экран округляет значения.

«Сохранить калории продукта» сохраняет энергию заменяемого ингредиента. Блок «Что изменится для собак» показывает калории до/после и проценты. При изменении более 3% можно подогнать обе порции по прежним калориям; это происходит только по нажатию. Сравнение сохраняется после перезапуска и экспорта.

Пример: при стандартных 7 днях, порциях 1000 и 200 г и выходе 660 г получается 8,4 кг еды, 12,727 закладки, 2863,636 г мяса и 941,818 г сухой гречки. Энергия закладки 967,63 ккал; Джина 1466,106, Уся 293,221 ккал/день.

## GitHub Pages

Git для Windows: https://git-scm.com/install/windows. GitHub CLI: https://cli.github.com/.

Если инструменты отсутствуют, установите их через PowerShell:

```powershell
winget install --id Git.Git -e --source winget
winget install --id GitHub.cli -e --source winget
```

После установки откройте новое окно PowerShell. Вход выполняет владелец самостоятельно: `gh auth login --web --git-protocol https`. Если аккаунта нет, создайте его на https://github.com/signup.

Публичная публикация допускается после явного согласия владельца: код и исходный рецепт будут доступны всем. Введённые порции, вес и свои рецепты остаются на устройстве и не публикуются.

`python tools/prepare_pages.py` готовит только разрешённые файлы в `.deployment/pages/ration-gina-usya`. Создайте репозиторий ration-gina-usya, отправьте эту папку в main и включите Settings → Pages → Deploy from a branch → main → / (root). Пустой .nojekyll отключает Jekyll. Все пути относительные, manifest и service worker ограничены папкой приложения.

Старые архивы, QR, локальные заметки, .deployment, .tools, экспорты JSON и сценарии прежнего хостинга исключены из публикации. Не отправляйте исходную рабочую папку целиком.

После появления настоящего HTTPS-адреса с доступными manifest, sw.js и иконками:

```powershell
python -m pip install qrcode pillow
python tools/make_pages_qr.py https://USERNAME.github.io/ration-gina-usya/
```

QR создаётся локально в QR_установка_iPhone.png; инструкция — Установка_на_iPhone.html. Эти файлы остаются локальными.

## iPhone и резервные копии

Safari → «Поделиться» → «На экран Домой» → «Добавить». Открывайте с этой иконки. После первого успешного открытия с интернетом приложение кэширует необходимые файлы. Работа на настоящем iPhone и авиарежим проверяются владельцем на устройстве.

Браузеру один раз запрашивается постоянное хранилище, если API поддерживается. Это не гарантирует сохранность: при удалении иконки или очистке Safari данные могут исчезнуть. Раз в 14 дней приложение напоминает об экспорте JSON; напоминание можно отложить или отключить в настройках.

При смене адреса данные автоматически не переходят. Сначала в старом приложении откройте Настройки → Экспорт JSON и сохраните файл в «Файлы» на iPhone. Затем в новом приложении откройте Настройки → Импорт JSON и выберите этот файл. Проверьте порции и рецепты, после этого удалите старую иконку. Старое размещение отключается только после подтверждения переноса владельцем. Если переносить нечего, старую иконку можно удалить сразу.

## Файлы

app.js — интерфейс и сохранение; core.js — расчёты и проверка JSON; products.js — справочник; style.css — оформление; sw.js — офлайн; version.js — общая версия; manifest.webmanifest и icons/ — установка.

Это калькулятор, а не ветеринарное назначение. Он не рассчитывает полноценность рациона и дозировки добавок. В исходном рецепте нет отдельного источника кальция.
